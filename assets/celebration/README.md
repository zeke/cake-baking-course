# Cake celebration media

AI-generated portraits and celebration clips for the example course, not recordings of real events. These are candidates, not approved final assets.

The four `*-upright.jpg` portraits revise the earlier framing. `group.jpg` is the shared starting image for both videos. `group-silent.mp4` has no audio; `group-dialogue.mp4` explores sequential congratulations. The earlier individual portraits are retained in [attempts](./attempts/).

[manifest.json](./manifest.json) records models, prediction IDs, and file hashes. Public copies omit private reference images, voice identifiers, and embedded generation inputs. Local originals are preserved.

The revised portraits are upright but still await likeness approval. Earlier portraits were superseded for posture and likeness. The silent clip shows bites and smiles. Dialogue is experimental: the audio follows Dane, Aly, then Brian, but mouth motion is not reliably limited to the assigned speaker.
