# Working on this course

This repository is an experimental agent-guided baking course. Keep it private and keep product-design or internal company information out of it.

Before changing course structure or metadata, consult the **latest canonical specification on GitHub**: https://github.com/agentschools/course-spec/blob/main/SPEC.md. The authoring guide is https://github.com/agentschools/course-spec/blob/main/skills/create-course/SKILL.md. Do not assume this document replaces that specification.

The initial format review used course-spec commit `c06dfd70a2f469d6ce0e1d023ad7316b7b986618`. COURSE.md has supported frontmatter only; six naturally ordered exercise files have stable slugs, one H1 each, tutorial sections, and checks in agent-instructions. A school supplies the default interview. Keep resource notes outside exercises/ so they do not become extra course steps.

Physical actions belong to the learner. Never claim an agent has observed a kitchen action or verified food safety from a chat answer. Report evidence honestly. A quiz is a knowledge check, not proof that baking happened. Keep quantities, pan size, temperature, and timing consistent across lessons. Preserve the recipe's untested status until a real test bake is documented.
